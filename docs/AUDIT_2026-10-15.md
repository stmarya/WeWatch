# Audit WeWatch — keamanan, AI, dan UI/UX

## Ringkasan

Baseline yang dibaca: `c1804006dda9f406b0793602c1ae7b0e84e61362` (main).
Audit memetakan seluruh source Python, template web, CSS/config deployment,
kontrak HTTP/Socket.IO, desktop UI dan 21 feature flag kamera. Perbaikan ada pada
branch `audit/wewatch-security-ai-ux-2026-10-15`; deploy/main tidak diubah otomatis.

**Hasil: lebih aman untuk pilot; NO-GO produksi luas sampai release gates selesai.**
Inventaris statis bukan bukti bahwa setiap tombol telah diuji end-to-end pada
semua browser/perangkat. Tes browser memakai kamera tiruan; tidak membuktikan
inferensi, microphone, native input, LiveKit/TURN, atau skala media nyata.

## Temuan keamanan dan perbaikan

| Temuan baseline | Risiko | Perbaikan/hasil |
| --- | --- | --- |
| Chat/caption/signaling/whiteboard/vote menerima event tanpa join sah | Tinggi: bypass room authentication dan kebocoran state | Membership guard pada setiap room event; rate limits; agent tidak dapat bertindak sebagai browser participant |
| `sender` WebRTC dipercaya dari payload | Tinggi: pemalsuan peer | Sender selalu socket SID server; hanya pasangan host/client, target dibatasi string |
| Remote commands tanpa persetujuan target | Tinggi: kontrol/pengambilan screenshot tanpa opt-in | Consent client eksplisit, revocable, expiry 10 menit; policy lokal native default deny |
| Shared agent token dan pairing self-claimed | Tinggi: pairing perangkat salah | Signed agent ticket terikat target_identity; static token hanya compatibility development opt-in |
| Hasil agent tidak terikat request | Sedang: spoof hasil/screenshot | Pending request terikat agent, admin, target dan expiry; hasil setelah revoke tidak diteruskan |
| Kick/end hanya meminta browser berhenti | Tinggi: client modifikasi bisa tetap aktif | Server disconnect; end meeting mengunci room |
| Token LiveKit memperpanjang umur invitation | Sedang: otorisasi melebihi TTL | Expiry media dibatasi sisa TTL; exchange client ditolak saat room locked |
| JSON list, non-string nama, state string, missing config | Sedang: crash/input ambiguity | JSON object/boolean/nama bounded, error terkontrol; bounded token validation |
| Status Redis diubah pada detached dict | Sedang: flags/consent/moderation hilang multi-worker | Explicit write-back; shared-state readiness admission guard |
| CSRF logout dikecualikan; media berpotensi di-cache | Sedang | Logout CSRF, no-store pada halaman/media privat, no-referrer |
| Automatic foto/audio/cloud/logging tanpa privacy gate | Tinggi untuk data sensitif | Explicit opt-in flags; local TTS default; keamanan tidak diubah oleh ambient speech |
| Pulse meng-clamp noise ke rentang sehat; FPS tetap | Tinggi bila dianggap medis | Estimator waktu sampling nyata, detrend/spectral quality gate; 0 = data tidak cukup; eksperimen default off |
| Valid placeholder LiveKit API keys dikirim di config | Tinggi saat expose | Config tidak berisi default keys; Docker environment keys wajib diisi |
| Dependency advisories | Tinggi menurut advisory dependency | Upgrade setuptools/Werkzeug; adapter model legacy tanpa pkg_resources; scan diulang |

Ini bukan pentest jaringan/forensik git-history. Tidak ada scanning host pengguna,
credential produksi, atau simulasi serangan terhadap deployment nyata.

Model MediaPipe sekarang dimuat terpisah: satu asset rusak tidak menggagalkan
semua model. Capability/health tersedia di status API, UI dan desktop memakai
policy yang sama, dan kamera tidak memproses frame capture lama berulang kali.
Health model menjelaskan startup readiness, bukan jaminan kualitas inference.

### Keputusan model

MediaPipe/dlib/EfficientDet dipertahankan. Tidak ada evaluation set berizin,
latency/CPU budget perangkat, atau bukti model alternatif lebih baik. Migrasi ke
LLM/cloud atau model baru tanpa benchmark akan menambah privacy/cost/latency dan
berpotensi merusak fitur. Perbaikan langsung berfokus pada input, scheduling,
scoring, fallback, dan kejujuran output. Estimator rPPG diganti algoritmenya,
tetapi belum divalidasi secara klinis/real-camera.

Legacy face-recognition-models 0.3.0 memakai `pkg_resources`, yang tidak ada pada
setuptools aman terbaru. Adapter lokal mengekspos empat path asset terpasang
melalui distribution metadata, memeriksa file dan menolak versi legacy asing;
tidak mengunduh model atau menjalankan kode tambahan. Full dlib inference masih
memerlukan pengujian installation/hardware terpisah.

## Evaluasi semua segmen UI/UX

| Segmen | Good design | Bad design / tindakan |
| --- | --- | --- |
| Login/admin session | Session HTTPOnly, token tidak diekspos di HTML | Logout aman ditambahkan; TLS/cookie secure dan account/RBAC per-person masih diperlukan |
| Client lobby | Preview + kontrol sebelum join | Media opt-in, token input, denial nyata tanpa “virtual live” palsu; join menunggu ACK; nama tampilan bukan credential |
| Stage/mic/cam/screenshare | Pola tombol/panel familiar | Labels icon, focus visible/reduced motion; permission state/reconnect/media tanpa perangkat perlu QA lintas browser |
| Chat/people/reactions | Escape user text, drawers terpisah | People search handler sebelumnya hilang: ditambahkan; reaction heart diselaraskan server; akses room wajib auth |
| Caption/voice | Caption teratribusi speaker | Web Speech punya batas browser/third-party; privacy notice dan language/accuracy QA belum lengkap |
| Whiteboard/polls | Room collaboration + bounded history | Stroke validated, sync authenticated; voter mapping tidak dibroadcast; vote per identity, bukan reconnect SID |
| Moderation/recording/lock | Hak host dicek server | Kick/end kini server-side; recording consent/retention dan SFU enforcement belum lengkap |
| AI telemetry/switchboard | Feature grouping dan status feed | Terlalu banyak kontrol; health/unknown/disabled jelas, toggle feedback setelah server sukses, unsupported fitur ditolak |
| Enrollment/snapshot/gallery | Face enrollment single-face, authenticated media | Foto/embedding/DB perlu delete & retention UX, overwrite confirmation, audit logs dan storage controls |
| Remote HR/desktop panel | Structured command allowlist | Kini opt-in revocable; host tidak menyalakan kamera diam-diam; mobile panel/focus/broad OS privilege masih gate |
| Layout/settings/PiP/PWA | Native browser capabilities dipakai | Tidak semua browser mendukung; service-worker/offline install path belum selesai; jangan mengklaim PWA offline penuh |
| LiveKit pilot | Separate SFU opt-in path | Token input + cleanup failed connection; SDK unpinned CDN, TURN/SFU moderation/legacy parity belum siap produksi |
| Legacy `/admin` template | Route redirect ke dashboard auth | Bukan entry point aktif; disertakan inventaris, tidak diuji sebagai production UI |
| Desktop GUI/launcher/enrollment CLI | Alternatif lokal untuk operator | Tidak diuji di GUI Windows nyata; feature policy disatukan; install matrix dan shutdown/reconnect perlu QA |

`UI_CONTROL_INVENTORY.json` merekam setiap kontrol HTML deklaratif, lokasi baris,
handler/action, headings, dan tombol yang dibentuk di script. Coverage setiap
entry eksplisit **static only**. Tidak mengubah inventaris menjadi klaim semua
click-path sudah diuji. Handler dasar inline yang hilang diperbaiki; runtime QA
juga memeriksa resolusi handler dan pencarian peserta.

## Hasil tes dan scan

Hasil final dibekukan di `AUDIT_VALIDATION.json`. Baseline memiliki 21 unit tests.
Suite ditambah regression untuk auth, consent, pairing, sender ownership,
media token TTL, no-cache, invalid inputs, kick, native expiry/replay, model
isolation, multisample identity, pulse synthetic, dan HTTP dashboard.

Browser QA memakai Chromium lokal, camera-denied fixture, 1365×900 dan 390×844.
Alur yang diuji: preview opt-in/denial, invalid/valid join, people search, drawer
opening, grant/revoke consent, leave, admin login/render, runtime handlers dan
mobile lobby overflow. Kamera, native Windows, audio nyata, SFU/TURN dan semua
aksi remote tidak diklaim teruji. Harness: `tools/browser_qa.cjs` dan
`tools/run_browser_qa_server.py` (loopback-only; jangan deploy).

Bandit dan pip-audit adalah pemeriksaan otomatis tambahan, bukan bukti tidak
adanya kerentanan. Temuan Bandit fixture credentials/exec AST tes bukan secret
produksi; subprocess node check/taskkill tanpa shell tetap perlu path/OS review.
Cakupan scan dependency mengikuti resolver Linux; Windows-only packages yang
terlewati marker memerlukan audit pada Windows. Full requirements resolver
(dry-run) bukan bukti dlib/native libraries berhasil dibangun.

## Prioritas pekerjaan berikutnya / NO-GO

1. **P0 produksi:** real device AI/Windows regression, model-quality benchmark,
   privacy consent/retention/delete, TLS+secret management, dependency/model provenance.
2. **P0 skala:** atomic capacity/identity admission Redis, distributed limits,
   SFU moderation/permissions, TURN auth/TLS, actual concurrent audio/video load.
3. **P1 UI:** full responsive in-call/remote panels, keyboard/focus trap/contrast,
   graceful device switching, coherent Indonesian localization, dependency health.
4. **P1 operasional:** durable audit log tanpa raw biometric/audio, observability,
   recovery/no-stale telemetry, migrations/backup/deletion, PWA install scope.

Tidak ada deployment, merge main, credential produksi, atau upload data pengguna
ke provider AI yang dilakukan oleh audit ini. Ikuti `SECURE_PILOT_SETUP.md`.
